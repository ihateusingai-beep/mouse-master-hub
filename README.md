# 滑鼠小達人 Hub

**Live:** https://ihateusingai-beep.github.io/mouse-master-hub/

## 機制
- **自由選關**（基礎 + 練習 + 趣味）
- **每關完成 → 金／銀／銅證書**（可列印 A4 橫）
- 寵物 XP + 貼紙仍保留

## 基礎關
| 關 | 技能 |
|----|------|
| 滑鼠走走 | 只移動入圈加分 |
| 打氣筒救氣球 | 左掣泵氣 |
| 禮物雨 | 右掣／兩指開盒 |

## 趣味關（新）
| 關 | 技能 |
|----|------|
| 小貓釣魚 | 移近 + 精準左掣 |
| 薄餅店 | 左掣加料 → 拖焗爐 |
| 星球快遞 | 移／點／拖／右 混合 Boss |
| 雙人接力 | 左半屏左掣 vs 右半屏右掣 |

## 證書門檻
- 鬥快／接力：金≥20 · 銀≥12 · 銅≥1
- 移動：金5 · 銀3 · 銅1
- 練習／趣味完成關：完成=金（progress≥5）
