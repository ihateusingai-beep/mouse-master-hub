# 滑鼠小達人 Hub

**Live:** https://ihateusingai-beep.github.io/mouse-master-hub/

## 機制
- **自由選關**（基礎 + 練習）
- **每關完成 → 金／銀／銅證書**（可列印 A4 橫）
- 寵物 XP + 貼紙仍保留

## 基礎關
| 關 | 技能 |
|----|------|
| 滑鼠走走 | 只移動入圈加分 |
| 左掣鬥快 | 10 秒原地左掣 |
| 右掣鬥快 | 10 秒原地右掣／兩指 |

## 證書門檻
- 鬥快：金≥20 · 銀≥12 · 銅≥1
- 移動：金5 · 銀3 · 銅1
- 練習關：完成=金（progress≥5）
